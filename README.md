# ODCE Arduino Scenario Kit

*Guide for the Arduino Scenarios A, B, and C*

The scenarios are designed but have not been run with students yet. The kit is supposed to be treated as a proposal. The development of this kit is based on the experience of a prior Arduino session run in the ODCE module in April 2026 and on the results of the master thesis “Planspiele als Vermittlungsinstrument organisationaler Problemlösungskompetenzen” by Christian Nguyen (TU Hamburg, 2026).

## Implementation in ODCE

Each scenario is a small Arduino build that teams of 4 to 5 students do twice. Between the two rounds one organizational parameter changes, while the task stays the same.

| Scenario | Parameter | Round 1 to Round 2 |
|---|---|---|
| A Conveyor Line | Interdependence | Pooled to sequential |
| B Greenhouse Control | Coordination Mechanism | Mutual agreement to standardization |
| C Parking Garage | System Architecture | Integral to Modular |

## Implementation Options

| Option | Pros | Cons |
|---|---|---|
| One scenario for all groups in one session (recommended) | One set of materials. One focus for observation. Shared debriefing, because all groups compare the same two rounds. | Students only examine one parameter |
| All scenarios in one session w/ one scenario per group | Students hear about all parameters in the debriefing | Needs one tutor per scenario and debriefing gets harder because groups compare different things |
| One session per scenario | Students meet all three parameters themselves | Too much course time and contrast gets weaker because students know the pattern |
